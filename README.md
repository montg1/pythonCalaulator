# Python Calculator

A simple, user-friendly calculator application built with Python and Tkinter. This project demonstrates how to create a Graphical User Interface (GUI) for performing basic arithmetic operations.

![Screenshot 2022-07-06 205239](https://user-images.githubusercontent.com/78199178/206444294-ce92db63-9b66-4aaa-ae3b-4d2572ce6863.jpg)

## 🚀 Features

* **Graphical User Interface (GUI)**: Clean interface built using Python's standard `tkinter` library.
* **Basic Arithmetic**: Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Visual Feedback**: Buttons for numbers and operations with a clear display screen.

## 🛠️ Technologies Used

* **Language**: Python 3.x
* **Library**: `tkinter` (Standard Python GUI library)

## 📋 Prerequisites

To run this application, you need to have **Python** installed on your computer.

Tkinter is usually included with Python standard installations. If you are on Linux and it's missing, you might need to install it separately (e.g., `sudo apt-get install python3-tk`).

## ⚙️ How to Run

1. **Clone the repository**:
```bash
git clone https://github.com/montg1/pythonCalaulator.git

```


2. **Navigate to the project directory**:
```bash
cd pythonCalaulator

```


3. **Run the calculator script**:
```bash
python calc.py

```



The calculator window should appear on your screen immediately.

## 📂 Project Structure

* `calc.py`: The main script containing the calculator logic and UI code.
* `helloworld.py`: A simple test script (can be ignored or used for testing basic Python setup).
* `Screenshot...jpg`: Preview image of the application.
